# File Organizer (Python)
Python automation script that sorts files into Images, Documents, Audio, Videos and Archives folders by file extension

## Overview
A Python script that organizes a messy folder by automatically moving files into folders based on their file type.

## Features
- Creates Images, Documents, Audio, Videos and Archives folders if they do not exist
- Detects each file's extension and moves it to the matching folder
- Skips existing folders and leaves unknown file types untouched

## Tools Used
Python (os, shutil), VS Code

## How to Run
1. Install Python 3
2. Copy file_organizer.py into the folder you want to organize
3. Run: python file_organizer.py
